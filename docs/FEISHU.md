# 飞书适配方式

## 边界

核心流程只识别本地用户 ID 和标准动作。飞书 Open ID、审批实例 ID、事件 ID 等外部标识应存放在独立映射层，避免业务模型被单个平台绑定。

## 推荐接入顺序

1. 使用企业自建应用完成 SSO。
2. 建立本地用户与飞书 Open ID 的最小映射。
3. 接收审批事件时先验证签名、时间戳与幂等事件 ID。
4. 把飞书动作转换为 `APPROVE`、`REJECT` 或 `CANCEL`。
5. 执行业务状态机后，再发送只含必要摘要的消息卡片。

## 权限原则

只申请当前模块需要的身份和消息权限。默认不要申请全量通讯录、所有群消息、云文档或多维表格读取权限。

## 凭证

App Secret、Token、加密密钥和 Verification Token 只能由环境变量或密钥管理服务注入。禁止写入源码、数据库导出、日志和截图。
