# Contributing

Thanks for helping improve Feishu Admin Workflow Kit.

## Good contributions

- A focused administrative workflow with tests
- A bug fix that preserves transition history
- A clearer Feishu adapter boundary or mock
- Documentation and privacy improvements

## Development

```bash
npm install
npm run verify
```

Keep examples synthetic. Do not submit real employees, approval records, addresses, group messages, tenant IDs, tokens or screenshots from an organization.

Open an issue before a large change. Pull requests should explain the business rule, include meaningful tests and keep platform-specific code outside the workflow core.
